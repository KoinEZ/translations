## Установка

У каждого русификатора своя инструкция — она указана в описании релиза и в
[оригинальном посте на Boosty](https://boosty.to/koinez). Общее правило: содержимое архива
кладётся в папку с игрой с заменой файлов, иногда дополнительно запускается `install.bat`.

Перед установкой сделайте резервную копию папки с игрой.

## Обновления

Boosty остаётся основной площадкой: новые переводы и исправления появляются там, сюда они
переносятся следом. Ссылка на оригинальный пост есть в каждом релизе.

## Использование

- Переводы можно свободно скачивать и использовать для личного прохождения.
- Коммерческое использование и продажа запрещены.
- Автор не связан с разработчиками игр; все права на игры принадлежат их издателям.
